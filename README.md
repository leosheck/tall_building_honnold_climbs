# Skyline Scale

A true-to-scale height comparison of tall buildings, towers and rock walls, including the structures Alex Honnold has free soloed (Taipei 101, El Capitan and Half Dome).

The page is a single self-contained `index.html` at the root of this repository. Open it in a browser, or serve it with GitHub Pages (Settings, Pages, deploy from the `main` branch, root folder).

Heights and climb details are sourced in the page footer and were checked in October 2026.
